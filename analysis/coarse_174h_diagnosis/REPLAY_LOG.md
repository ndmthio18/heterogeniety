# Isolated diagnostic provenance

Accepted v12 source, binary, input and raw fields are untouched. The diagnostic binary is a separate read-only primary-state loader plus face exporter. It calls the original volume-variable, Neumann, advective and molecular-diffusion code. No Newton solve, restart integration, changed physical parameter, or new 174 h trajectory is involved.

`build_replay.py` clones the accepted source under a new remote audit directory, adds `replay_member.hh`, replaces only the executable entry point with `replay_main.cc`, and uses the archived compiler/link command. Build manifests and diffs preserve exact hashes. The pressure, phase state, switching variable, salt mole fraction and equivalent solid inventory are reconstructed from Float64 VTU output by DOF id. Phase-state support is explicitly restricted to the actually observed liquid-only/both-phase states; no clipping is used.

The five pilot states (1/6,24,60,120,174 h) reproduced original water/salt inventories, material inventories and bottom/interface net fluxes with maximum scaled discrepancy 2.4e-9. A full saved-state replay is gated independently at every frame. Error normalization uses absolute 1e-10 floors for nearly cancelling net fluxes; raw values are exported, so this is not a blanket relative-error claim on a zero flux.

The first horizontal diagnostic used literal y=10/20/30 mm planes; no such faces exist on this vertically graded mesh. It correctly emitted no horizontal faces. This diagnostic-selection issue was repaired in a **separate** `native_vertical` build using actual nearest mesh levels, y≈11.0026,19.0235,30.2801 mm, retaining the first attempt and leaving the already validated bottom/interface replay unchanged. Seven checkpoint replays verify 2304 horizontal faces (three planes ×768). These planes are labelled by actual height/depth in exported data. There is no change in solver physics.

Boundary Neumann flux is per area and is multiplied by native face area/extrusion **once**. Interior advective/diffusive flux methods already return integrated face flux and are not multiplied by area a second time. Interface faces are counted once from the F36 side. Horizontal faces are counted once with upward normal. Gross fluxes are formed per face before summation. Native geometry counts, donor-state concentration identity, signed/gross fixture and exact native-net aggregation tests are recorded in `results/flux_analysis_checks.json`.

Full replay evaluates stored states every600 s; original accepted ledger usually integrates at300 s. Trapezoidal gross integrals are therefore approximate, and their net counterparts are compared to the original accepted cumulative ledger. 20/60-minute downsampling tests measure diagnostic quadrature sensitivity, not solver time-step or spatial convergence. The original ledger remains the closure authority.

During figure QA an analysis-only endpoint issue was found: the experimental workbook continues beyond174 h, and interpolation beyond the model endpoint produced zero terminal model rates. The comparison now explicitly limits paired intervals to174 h. No extrapolated model rate remains, and original weighing records are retained.
