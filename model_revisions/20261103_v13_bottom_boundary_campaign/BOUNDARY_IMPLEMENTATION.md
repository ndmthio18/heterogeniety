# Bottom-boundary implementation and assumptions

B0–B3 use the frozen accelerated v13 executable without physical code changes. R_ref=288856.0397652994 Pa s/m, using initial saturated coarse bottom mu=0.0011126174745057953 Pa s, half-cell distance0.002030005m, K=7.819185772155931e-12m², kr=1. Reference values come from the SHA-verified accepted initial fields and geometry. Rf=0,28885.60397652994,288856.0397652994,2888560.397652994 Pa s/m. Each Rf is one common constant across both sands. It has no explicit temperature dependence; the original half-cell donor viscosity remains composition/temperature dependent. These brackets are not P3 measurements.

G1–G3 add a4.5mm full-area porous layer below y=0, retaining every original sand cell and the x=.025 material interface. Six vertical filter layers form35328 total cells; twelve-layer short screen has39936. Flow, solute diffusion and energy transfer use the same conservative native internal FV fluxes across sand/filter and within filter. No extra Robin filter resistance is imposed. Reservoir absolute level remains y=.02m, not .02m above the new filter bottom.

Ports of2/5/10mm diameter lie at the centre of the filter's bottom face. Exact polygon/circle overlap assigns a fractional open area to each intersected boundary face; total areas equal pi*d²/4. Port area is verified against the actual native face geometry, not a2D slit. The old unsupported CentralAperture mode remains rejected. This is a simplified port-at-filter-bottom model, not a reconstruction of an unknown lower plenum. Subface pressure is represented at the existing face integration point; particularly the2mm port is radially under-resolved. Exact area does not imply spatial convergence.

Exploratory filter phi=.35; common fixed intrinsic K=1.7333127738454676e-11m² makes mu_ref*4.5mm/K=R_ref. Unlike constant-Rf B2, explicit filter resistance then follows local fluid viscosity. The filter inherits the coarse Brooks–Corey curve and the existing granite inert thermal surrogate. These are explicit unmeasured filter assumptions, not measured P3 glass properties; salt equilibrium and fixed-hydraulics inventory semantics remain unchanged. External filter walls inherit the registered plexiglass heat boundary; internal heat coupling is conservative. No separate plenum heat model, crystallization heat or crust is added.

Perturbation normalization/correction remains sand-only; filter initial solution stays1M. G budget.csv retains the historical left/right half-domain columns (including each filter half); **material_budgets.csv gives sand-only F36, sand-only W3 and filter separately**, with water/total-salt/energy balances and explicit seed impulses. Global inventory includes the added filter liquid and solid salt. These scopes must not be mixed in comparisons.

Native flux kind0=external bottom,1=sand F36→W3,2=upward sand horizontal sections,3=sand→filter,4=upward mid-filter section,5=filter left→right. Gross positive/negative fluxes are computed facewise before summation. Advective and diffusive water/salt fluxes and heat are separate. For G, sand replenishment is kind3 (inflow negative), while external reservoir loss is kind0. Native face maps include pressure and temperature.

Tests: actual circular area and both-material donor/enthalpy probes; hydrostatic relaxation; zero-change B0 code limit (ExplicitFilter=false); reaction/rollback; separate3-region balances at every accepted step; G2 dt150 and doubled vertical-filter-resolution screens. A finite-volume, finite-storage explicit filter is not algebraically identical to a Robin boundary even when its initial through-thickness resistance matches. No exact equivalence of those two models is assumed.

Remaining limitation: full radial refinement and full174h grid/dt convergence are absent. Do not interpret small geometry effects below numerical screens as physical evidence, or claim these hypothetical ports identify the actual apparatus.
